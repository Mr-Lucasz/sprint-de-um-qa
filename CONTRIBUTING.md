# Contribuindo

Obrigado por querer melhorar o material.

## O que é bem-vindo

- Correção de erro de conteúdo, de português ou de link quebrado.
- Passo de uma lição que não funciona mais (o Sauce Demo e as ferramentas
  mudam com o tempo).
- Um exemplo mais claro para uma lição.
- Uma lição ou um desafio novo, no formato das fases existentes.

## O que não é

- **Corrigir os defeitos do Inscrevi.** Eles são intencionais: são o que os
  desafios pedem para encontrar.
- **Publicar gabarito.** Issues, pull requests e discussões que listam os
  defeitos do Inscrevi ou trazem os desafios resolvidos tiram a graça de quem
  vem depois. Os seus bugs vão nas Issues do **seu fork**.

## Como enviar

1. Abra uma issue descrevendo o problema ou a ideia, sem spoilers.
2. Para mudanças pequenas, pode abrir o pull request direto.
3. Mantenha o formato das fases: `README.md` é a lição (teoria e exemplo
   resolvido no Sauce Demo) e `DESAFIO.md` é o desafio no Inscrevi (material,
   tarefas, o que entregar e o que conferir).
4. Escreva em português, em frases curtas, e confira os links.

## Formato de um desafio

```
# Desafio NN · Título
Lição desta fase: link
(contexto em duas ou três frases)
## Material
## Tarefas (tempo)
## O que você entrega
## Confira antes de seguir
```
