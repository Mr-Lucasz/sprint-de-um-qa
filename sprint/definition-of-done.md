# Definition of Done

Uma história só é considerada pronta quando:

- [ ] Todos os critérios de aceite foram verificados e têm evidência (caso de teste executado ou teste automatizado).
- [ ] Os cenários principais e os de borda (valores limite, partições inválidas) foram testados.
- [ ] Não há defeitos abertos de severidade crítica ou alta ligados à história.
- [ ] Defeitos de severidade média ou baixa estão registrados como issues e priorizados com o PO.
- [ ] Os testes automatizados da história rodam no pipeline e estão verdes.
- [ ] A API está documentada no Swagger (`/docs`) e o comportamento bate com a documentação.
- [ ] As telas novas podem ser usadas só pelo teclado e todos os campos têm rótulo.
